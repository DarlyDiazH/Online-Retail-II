# Online Retail II - Portal de Comercio Electrónico

## Descripción del proyecto

Desarrollo de un portal de comercio electrónico que implementa los resultados de un proyecto de Big Data realizado a partir del conjunto de datos Online Retail II.

La plataforma permitirá consultar productos, registrar usuarios, visualizar información de segmentación de clientes y ofrecer beneficios personalizados según el segmento asignado.

El proyecto tiene fines académicos y contempla un proceso de compra simulado, sin integración de pasarelas de pago reales.

## Tecnologías

- **Frontend:** React + Vite
- **Backend:** Python + FastAPI
- **Base de datos:** Neon PostgreSQL
- **Control de versiones:** Git y GitHub

## Módulos del proyecto

1. **Autenticación y perfil de clientes:** registro, inicio de sesión, perfil y consulta de segmentación.
2. **Catálogo de productos:** visualización, búsqueda, filtros y detalles de productos.
3. **Carrito y compras:** gestión del carrito, descuentos personalizados y simulación de compra.

## Estructura del repositorio

- `frontend/`: aplicación de usuario.
- `backend/`: servicios y lógica del servidor.
- `docs/`: documentación del proyecto.
